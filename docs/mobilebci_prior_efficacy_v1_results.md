# 머리 움직임 metadata 실험: 완료, 현재 후보 종료

2026-09-11. **16명 공개 데이터로 336회 학습을 끝냈지만, metadata의 실용적 추가
정확도 이득이나 보정량 감소는 확인하지 못했다.** 미리 정한 유지 조건을 통과하지
못했으므로 이 후보는 `CLOSED_NEGATIVE`로 종료한다. 결과를 본 뒤 설정을 바꾸어
같은 예산의 연장 실험으로 취급하지 않는다.

## 무엇을 실제로 했나

연구목표는 그대로다. 새 사람의 적은 SSVEP 보정 예시를 학습할 때, EEG 자체의
품질 정보에 **그 예시를 기록하던 때의 실제 머리 움직임**을 더 주면 도움이 되는가?
Query 때 IMU를 계속 넣는 멀티모달 분류기나 손상 복구 실험이 아니다.

- 공개 16명 × 3보행 조건의 EEG–IMU 96파일 metadata를 검사했다. 전부 통과했다.
- 각 클래스의 첫 1/2/3/5개 예시만 학습에 쓰고, 그 예시를 모으기까지 지나간 모든
  trial을 보정 비용으로 셌다. 평가는 항상 trials 41–60으로 고정했다.
- 96파일의 raw_x를 한 번씩 해독해 허용된 EEG 구간과 support IMU 특징을 만들었다.
  MAT 구조 때문에 전체 배열은 해독하지만, query IMU나 미래 구간의 요약을 학습
  특징으로 쓰지 않았다. 숫자 해독 누적 4.58GB, 저장 feature cache는 2.14MB다.
- 참가자를 분리한 inner 288회에서 설정·보정량을 결정하고 모두 저장한 뒤, outer
  48회를 평가했다. 같은 사람의 세 조건은 항상 함께 이동했다.
- 실제 336 fits / 33,600 steps를 CPU 한 스레드에서 **58.41초**에 완료했다.
  원시 긴 파형 대신 동일 계산에 필요한 작은 행렬을 사용했다. 추가 fit은 0이다.

## 핵심 결과

클래스별 정확도를 균등하게 평균한 balanced accuracy다. 아래는 클래스당 1·2개
예시의 평균이며, 사람·조건도 균등 가중했다.

| 학습 방법 | 정확도 |
| --- | ---: |
| Q: EEG 품질 + 공통 조건 | 66.52% |
| Q2: 더 풍부한 EEG 특징 + 같은 크기의 추가 모델 | 66.70% |
| QM: 실제 머리 움직임 추가 | 66.56% |
| SHAM: 다른 사람 움직임으로 잘못 짝지어 다시 학습 | 66.73% |

QM−Q는 **+0.046 percentage points**, 참가자 bootstrap 95% 구간은
**−0.368~+0.434 pp**였다. 미리 정한 +2 pp 실용 기준에 못 미치며,
Q2보다 −0.142 pp, SHAM보다 −0.171 pp였다.

보정량은 평가 정답으로 골라내지 않았다. 학습 참가자에서 80%를 달성하는 최소
예시 수를 정하도록 했지만, 모든 arm·outer fold에서 목표에 못 미쳐 최대 k5로
돌아갔다. 새 참가자에게 적용한 결과도 동일했다.

| Source에서 미리 선택한 정책 | Q / Q2 / QM / SHAM 모두 |
| --- | ---: |
| 클래스당 학습 예시 | 5개, 총 15개 |
| 실제 수집한 prefix 비용 | 평균 21.85 trials |
| 정확도 | 71.69% |
| Run별 80% 도달 비율 | 47.92% |
| QM의 Q 대비 보정 trial 절감 | **0%** |

Recording 시작 기준 ready-time proxy도 평균 203.26초로 같았다. 약 4초 preroll과
평가 전 대기 구간이 있으므로 이를 실제 온라인 전체 준비시간이라고 부르지 않는다.
IMU 장착 비용도 측정되지 않았다.

참고로 학습된 prior가 없는 identity-R는 저예산 66.25%, QM 정책과 같은 k5에서
71.03%였다. Target 보정 예시를 쓰지 않는 고정 reference-CCA는 63.03%였다.
보정 예시를 쓰는 방법의 정확도가 이 무보정 기준선보다 높았지만, **metadata 추가로
보정량을 줄인 증거는 없다.** 알고리즘도 다른 비교이므로 차이를 보정 예시만의 인과효과로
분리하지 않는다. 같은 공개 replay의 결과이며 일반적인 방법 순위도 아니다.

## Metadata를 안 넣어서 실패한 것은 아닌가

그 경우와는 구분했다. QM 84개 fit 전부에서 모델과 Q/common을 고정한 채 M만
다른 source 참가자의 값으로 바꾸면 prior와 class score가 변했다. Source score의
최대 변화는 fit에 따라 0.000409~0.021209였다. 실제 외부 평가에서도 QM/Q의 선택이
k1에서 14/960, k2에서 7/960, k3에서 10/960번 달랐지만 k5에서는 0번이었다.

즉 **M이 학습 경로에 연결되고 계산을 바꾸는 것까지는 성공했다. 그러나 새로운
사람에게 필요한 실용적 개선으로 이어지지 않았다.** Q2와 SHAM도 못 넘었으므로
작은 차이를 metadata 고유의 유용한 정보라고 주장할 수 없다.

독립 검산은 저장 예측에서 정확도·source 선택·비용·bootstrap을 다시 계산했고,
동시에 참가자 분리·336 fits·SHAM donor·수치 안정성을 확인했다. 불일치 0이었다.
새 raw 재추출이나 optimizer 재학습까지 독립 복제한 것은 아니다.

## 해석 한계와 다음 행동

- 이것은 **머리 gyro 요약 2개 → 제한된 대각 residual prior**라는 한 기작의 부정
  결과다. Metadata 전체가 무용하다거나 다른 측정에서도 불가능하다는 증거는 아니다.
- 16명 개발 데이터와 고정 cross-fit 예측에 대한 구간이다. 학습 재표집 불확실성
  전체를 포함하지 않는다. 44/48 runs가 같은 class 순서를 공유하며 query index는
  입력에서 제외했다. 최근접 SHAM도 분포보존 permutation 검정은 아니다.
- Event-relative 창은 사전 고정했지만 물리적 자극 onset은 확증하지 못했다.
  성능을 본 뒤 유리한 offset을 찾는 작업은 이번 실험의 확인 분석이 될 수 없다.
- 현재 후보의 336/336 예산을 닫고, 기존 임피던스·source39 부정 결과와 함께 보존한다.
  α·창·특징을 조금씩 바꾸어 양성이 나올 때까지 탐색하지 않는다.
- 다음 후보는 **현재 M이 무엇을 추가로 알려 줄 수 있는지 다른 기작의 근거**와
  공개 자료의 측정·시간 정의를 먼저 확보해야 한다. 단순히 참가자 수부터 늘리거나
  이번 16명을 독립 검증 표본으로 재사용하지 않는다.
- 유망한 새 후보가 별도 사전계획에서 생긴 경우에만, 보지 않은 코호트에서 동일
  대조군과 source-fixed 보정 정책을 확인한다. held60·외부 요청·유료 사용은 계속
  별도 승인 대상이다. 새 후보 실행 예산은 아직 열지 않았다.

`academic-research`는 연결 성공·조건부 효능·보정 절감을 별도 주장으로 기록하게 했고,
`coordinate-worktree-changes`에 따라 root만 작성하고 두 agent가 읽기전용 검산했다.
새 문헌 검색이나 PDF 정독을 수행했다고 주장하지 않는다.
