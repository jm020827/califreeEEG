# Joint harmonic v1 최종 보고 — 검산 완료, metadata 추가 이득 미확립

2026-09-23 KST. **고정한 C1 연구 루프를 종료한다.** 새 기작의 공동학습을 직접 시험했고,
승인된 검산 보완 후 저장 결과의 독립 계산을 확인했다. 이 후보에서 metadata의 추가
성능 이득·보정량 절감을 얻지 못했다. 원 저보정 SSVEP 연구 질문 자체의 폐기는 아니다.

## 무엇을 시험했나

동일한 외부 block/channel 임피던스를 사용하되 EEG의 복소 harmonic 표현과, 적은 보정
EEG로 개인별 class prototype을 만드는 metric을 함께 학습했다. 기존 frozen embedding
precision/TRCA 규제/source routing 및 zero-calibration conditioning과의 차이는
[실행 전 계획](joint_harmonic_program_v1_plan.md)에 명시했다. 같은 측정값의 유용성을
미리 증명하라는 관문 없이 Q/Q2/QM/SHAM을 같은 그래프·초기값·episode·튜닝 기회로 비교했다.

Source39 개발 참가자, dry/wet,2초 EEG창,12 target,첫1/3/5 complete block 보정과
후기5 block 평가를 고정했다. Inner24+outer24=48fits/48,000updates,24 final 모델을
모두 동결한 뒤 단회 개발평가를 했다. 후보는 사전 고정한1개이고 자동 C2/C3 예비군은 없다.

참가자·interface 동일 가중, 두 seed 평균. 아래는 독립 저장 결과 검산을 통과한 수치다.
저보정 평균은 총12개와36개 보정 trial 조건의 평균이며, k=1은 target당1개를 뜻한다.

60개 보정을 쓴 Q도51.99%이므로 강한 저보정 기준선/SOTA 성공이나 metadata 성공으로

Source validation에서80%를 달성하는 k가 없어 모든 arm/fold가 최대60trial fallback을
선택했다. QM의 적용 성능은51.53%이며 **계산된 보정 획득량 절감은0%**다.80%를 달성하면서
보정을 줄였다는 주장을 할 수 없다. 별도의 사후80% 관측 도달 비교도 Q/QM의156개
seed×사람×interface 조건 중68개 공동 도달/88개 공동 미도달, 신규 도달·상실각0,
공동 도달 조건의 평균 trial 절감0이다.156조건은156명의 독립 참가자가 아니다.

보정 비용은 이미 수집된 complete-block prefix의 오프라인 재생이며 새 온라인 보정
실험이 아니다. EEG창 사용시간과 cue/rest/전극 준비/임피던스 측정 포함 준비시간은 다르다.
전체 준비시간 절감은UNKNOWN으로 남긴다.

## 검산 오류를 어떻게 해결했나

NPZ는 Q/Q2 원소를 정확히 보존했지만, 추출 때의 임의 메모리 배치(strides)를 보존하지
않았다. 인공 MAT/F 경로에서 이 변화만으로 float32 prefix 평균에 약1e-7 차이가 생겼다.
실제 재감사 전에 고정한 배치 복원으로 **허용오차를 늘리지 않고** 모든 저장 normalizer를
재현했다. 원본 strides 영수증은 없지만, 인공 재현과 실제48모델 통계의 일치는 이 설명을
지지한다. EEG값·모델·학습·평가 점수·과학 기준은 수정하지 않았다.

[승인된 보완 계획](joint_harmonic_audit_r1_plan.md) 및
[실행 전 생성 검증](reports/joint_harmonic_audit_r1_qualification.json)에 따라:

- 추가 코드 보완1회, 생성 시험2회/총4.10초, 새 optimizer update0.
- 실제 저장 결과 재감사1회, feature cache1회, 외부2.80초/내부1.629초.
- Source normalizer48개: 최대 mean 차3.55e-15, scale 차6.66e-16;
  원 `rtol=atol=1e-10` 유지.
- Final 모델24개,112,320개 저장 trial 판정: 독립 NumPy logit 최대차7.87e-6,
  argmax 차이0; 원 최대차1e-4 기준 유지. 이 수는 반복 조건의 검산 건수이지 표본 수가 아니다.
- 저장 source validation의12개 선택, 참가자/조건/seed별 정확도, 주요 bootstrap,
  보정 비용과8개 승격 gate를 확인했다.6개 gate 실패/2개 통과로 유망후보가 아니다.
- 원 실패 audit와 원 auditor 소스는 보존했다. result/weights/예측/동결/원 terminal,
  science plan/config 및 기존 보호6개 과거 기록의 해시는 유지됐다.

검산 범위는 **저장 특징·가중치·점수와 보고 통계**다. Raw 전처리와 학습의 독립 재실행,
CCA forward 독립 재현, 독립 참가자 replication을 수행했다는 뜻이 아니다. Source의
M 교환 민감도 진단은 보존하되, 이를 효능이나 최종 query 개입 효과로 바꾸어 해석하지 않는다.

## 유지·종료 및 후속 검증 계획

1. **종료:** C1의 학습/튜닝/실자료 탐색과 승인된 r1 검산. 예산을 사용했고 유망 조건을
   충족하지 못했다. 같은 후보의 seed/학습량/조건을 추가하거나 이름을 바꿔 재개하지 않는다.
2. **유지:** 같은 측정값도 새로운 표현·상호작용·공동학습에서 유용할 수 있다는 연구 가능성.
   이번 결과는 이39명·특정 모델·기작·예산에서의 이득 미확립이지 metadata 일반의 무용성 증명이 아니다.
3. **후속 독립 검증:** 현재 후보는 승격하지 않으므로 held60을 개봉하지 않는다. 후일 별도
   프로그램을 승인한다면 기존 기작과 구별되는 이유·예상 차이·총 예산을 먼저 기록하고,
   공통 강한 기준선과 동일 B의 Q/Q2/QM/SHAM을 함께 평가해야 한다. B 개선만을 무한히
   선행시키거나 M 유용성 사전 증명을 필수조건으로 만들지 않는다.
4. 새 후보가 사전 정확도/비용/개인별 위해 기준을 충족할 때만 독립 참가자·acquisition 조건,
   분석 단위/필요 표본 수·최소효과·보정 획득 비용을 사전 고정한 단회 확인을 제안한다.
   Held60/외부 자료 요청·연락/유료 자원은 계속 별도 승인이다. 이번 루프에서는 모두0이다.
