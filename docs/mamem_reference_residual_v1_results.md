# 공통값을 넘는 차이는 있지만, 그대로 다음 기록에 전달되지는 않았다

2026-09-13. 가용공간 약293GiB를 확인한 뒤 기존 공개자료 10명×2기록에서
**300개의 DIN event 창**을 한 번 분석했다. 새 EEG decode·분류·학습은 모두0이다.
사전 판정은 **`RETIRE_FULL_RESIDUAL_ROUTE`**: 앞선 A기록의 class별 잔차를
그대로 B기록의 reference에 전달하는 경로를 종료한다.

## 쉽게 설명하면

앞선 S001 진단에서는 nominal 주파수보다 지원 기록에서 만든 주파수가 잘 맞았다.
하지만 그것이 **모든 사람이 공유하는 장치/기록 설정 차이**를 고친 효과인지,
**그 사람에게만 필요한 보정**인지 구분되지 않았다.

이번에는 매번 본인을 뺀 다른9명의 자료로 공통값을 만들었다. A와 B의 공통값도
따로 계산해 두 기록 역할의 공통 차이를 제거했다. 그런 다음 본인의 A에서 class마다
첫 trial 하나(총5개)를 사용해 얻은 차이를 B 공통값에 전달했다.
비교 정답은 **B의 기록된 event 주파수 3회 평균**이다. EEG가 맞힌 target 수가 아니다.

결과는 “사람/기록마다 차이가 아예 없다”가 아니었다. **차이는 관측됐지만,
첫 기록의 차이를 다음 기록에 그대로 적용하는 방법은 대체로 더 부정확했다.**

## 왜 이렇게 나왔는지 어디까지 알 수 있나

이 결과만으로 장치 clock 변동, event 추정오차, 실제 시간변화 중 원인을 확정할 수는 없다.
확인된 것은 **고정한 full classwise 잔차 전달이 강한 공통값보다 나빴다**는 사실이다.
A→B는 파일 역할에 따른 cross-run 비교이며 실제 획득 시간순서를 독립 확인하지 않았다.
같은 참가자를 두 common bank 모두에서 제외했지만, fold들이 source를 공유하므로
완전히 독립적인10개 검정도 아니다. 같은10명은 이미 개봉한 개발자료다.

부정 결과는 다음처럼 범위를 좁혀 해석한다.

- v2의 M2→PSD shrinkage 실패와 이번 **reference full잔차 전달 실패**는 서로 다른 결과다.
- 앞선 S001의 12/15→14/15 관찰은 그대로 남는다. 이번은 공통bank와 비교한 구조 검사다.
- 불안정한 M을 부분적으로만 반영하는 학습이 유용할 가능성을 이번 gate가 배제하지는 않는다.
  다만 **이 결과를 보고 계수를 바꾸어 같은 예산을 자동 연장하지 않는다**.
- Q/Q2/QM/SHAM, EEG 정확도, 보정 trial 절감은 이번에 평가하지 않았다.
  “metadata에 아무 정보도 없다” 또는 “metadata 학습은 성공했다”는 결론 모두 부당하다.

## 비용과 접근 경계

각 참가자의 지원은 class당1trial=총5trial이다. 선택 자극 길이25초, 선택 DIN 분석창
합10초지만, 선택된 마지막 trial까지 prefix는 **445.904–457.828초**다.
전체 A기록은 **472.424–484.964초**이며 적격성 검사에는 전체 DIN이 필요했다.
실제 query-ready/setup은 UNKNOWN. 온라인 보정시간 절감으로 환산하지 않는다.

모든 A10기록을 저장·seal한 뒤 B10기록을 열었다. 파일별 전체 byte hash와 header 확인
각20회, DIN_1/samplingRate load 각20회; EEG는 header의257×T만 확인하고 수치 decode0.
A150/B150창 event-frequency 진단을 했으므로 B metadata 추출0이라고 쓰지 않는다.
B의 EEG predictor 사용은0이다. S001/c/d/e/held60, 기존feature NPZ 수치 접근0.
새다운로드/추출/네트워크/사람에게 요청/유료/설치/삭제/push도0.
