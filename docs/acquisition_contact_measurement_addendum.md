# 접촉 metadata 후보의 추가 측정·비용 규칙

2026-09-14 KST. 향후 후보의 자격·사전설계용 추가 규칙이다. 기존 종료 실험의 계약이나
판정을 소급 수정하지 않는다. 목표는 **같은 준비 조건에서 외부 M을 학습에 사용해
Q/common 이상의 이득과 실제 labeled calibration 부담 감소를 얻는가**로 유지한다.

근거: [Pre-Gelled 원문 검토](pregel_public_fulltext_v1_results.md), 특히 PDFp.3 II.C,
p.4 II.G, pp.5–7 Fig.4/8. 아래는 저자 결과 자체가 아닌 연구자 측 설계상의 추론이다.

## 후보를 학습으로 넘기기 전에 요구하는 schema

| 구분 | 반드시 확인할 필드/의미 | 금지하는 대체 |
| --- | --- | --- |
| 값 | 실제 channelwise 측정, 단위, validity/missingness, 값의 변환 이력 | 전극명·임피던스 상한·그룹 평균을 개인값으로 채움 |
| 공통 측정 맥락 | 장치/측정주파수/시험전류/working-reference 정의/측정 모드 | 모든 수치를 단일 채널의 순수 피부 저항으로 해석 |
| 시간 | 측정시각, clock/offset, support와 join, 사용할 때 측정 이후 경과시간 | 논문의6분간격 측정을 임의로6개BCI block에 연결 |
| 개입 | 조정·재장착 전후, 전극 교체, 재측정 구간, 안정화 대기 | 최초 M과 조정 후 EEG의 상태가 같다고 가정 |
| 비용 | labeled trial 수, 측정/조정/대기/실패시간, 최초 query-ready 시각 | label 감소만 보고 추가 준비시간은0으로 처리 |

장치 정의 등 공통정보는 Q/Q2/QM/SHAM 모두 동일하게 받는다. Dataset/subject ID lookup이나
학습 참가자 암기로 실제 측정값을 대신해서는 안 된다. 반면 처음 보는 참가자에게 실제로
한 번 측정한 M은 세션 내 상수라도 후보가 될 수 있다. 측정 횟수1회라는 이유로 배제하지 않는다.
시험 모드와 EEG모드가 다르면
동시 측정으로 포장하지 않고, 유효한 pre-query 값이 다음 구간에 유지되는지를 따로 검증한다.

## 두 효과를 분리한다

- **학습 효과(원 목표):** 모든 arm에 동일한 준비·조정 절차를 적용한 EEG에서 실제 M을
  학습에 사용했을 때의 차이. Q2로 추가용량, 조건부SHAM으로 pairing, 직접M 처리로
  학습 자체의 기여를 분리한다. 사람이 분리된 source-only 개발/선택을 사용한다.
- **준비 개입 효과(별도 연구):** M을 보고 전극을 다시 누르거나 장착을 바꾸는 정책.
  이는 EEG 자체와 비용을 바꾸므로 원 목표의 metadata learner 결과로 합치지 않는다.
  새 사람 실험이나 정책 비교는 여기서 승인/실행하지 않는다.

M→decoder의 단조 규칙은 문헌만으로 고정하지 않는다. 향후 적격 실제 M이 확보되면
one-shot에서 실제로 작동하는 insertion point를 후보별 실행 전에 고정한다. 매개변수만 바꿔
종료한 reliability/source-routing 후보를 새 후보로 세지 않는다.

## 반증과 보고

- 실제파일·시점·조정상태 join 불가 → 해당 후보의 학습 진입 중단. 그림을 digitize해 원자료로 쓰지 않음.
- QM이 matched Q/Q2/SHAM/direct-M 기준을 못 넘음 → 그 후보의 사전 기준대로 수정 또는 종료.
- 필요한 정확도와 허용 악화·불확실성 기준은 결과 전에 수치로 고정한다. p>.05를 동등성으로 쓰지 않음.
- Label trial은 줄어도 총 query-ready 비용이 증가하면 두 지표를 분리 보고; 실제 부담감소를 선언하지 않음.
- 새 raw release/실측 M/학습효능은 이번 문헌 검토에서 확보하거나 증명하지 않았다.

기존 negative, held60 봉인, 외부 사람 요청·유료 별도 승인 경계는 그대로다.
