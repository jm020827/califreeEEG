# Direct-M envelope-r1 결과 — 실행 완료, 임피던스 증분 미확립

2026-09-07. [승인된 입력 복구](native_subset_m_envelope_r1_execution.md) 후 같은 과학 계획을 처음 끝까지 실행했다.
**입력 연결 오류는 해결됐지만, 이번 방식에서 임피던스가 추가 보정 부담을 줄였다는 근거는 나오지 않았다.**
공식 산출물 status는 `DEVELOPMENT_ASSESSMENT_COMPLETE`이며 이는 효능 성공 판정이 아니다.
[이전 start-only 실패](native_subset_m_source39_v1_results.md)는 수정·덮어쓰기 없이 보존했다.

## 쉽게 말하면

먼저 EEG를 보고 '보정 예시를 모두 쓸지, 어느 블록을 뺄지' 정하는 Q는 8조건평균에서 그냥 모두 쓰는 FULL보다 좋아졌다.
그러나 여기에 전극 임피던스 M을 더한 QM은 거의 같은 정답을 냈다.
즉 **보정 예시 선택의 개선은 관측했지만, 그 개선을 metadata 덕분이라고 할 수는 없다.**

Q는 순수한 context-blind EEG-only가 아니라 EEG + 공통 interface/프로토콜/측정순서다.
QM이 더 받는 정보가 실제 pre-query 임피던스이며 원본 helper·특징·split·SHAM 배정은 바꾸지 않았다.
k3/k5는 전체 예시3/5개가 아니라 **12개 class 각각3/5회, 총36/60개 labeled trials**다.
