# 두 공개자료 후보를 학습으로 넘기기 전의 관문

> 2026-09-12 후속: [공개 provenance 확인](public_provenance_resolution_v1_results.md)으로
> 단일 상자 실험의 optical DIN 저자 보고가 확보됐다. 아래 조건부 출처 질문은
> 당시 단계의 기록이며, 실제 파일 연결·Dataset II/.flash 의미·공통 보정 후 잔여
> M 정보와 누출/비용 관문은 여전히 남아 있다. 모델 실행 상태는 아니다.

2026-09-12. 원 저보정 SSVEP 목표를 위한 설계 메모다. 아래는 **검증 전 가설**이며
새 학습 후보·실행 계약이 아니다. 자료 조사 결과와 독립 검토를 통합해 판정한다.

## 파일이 있다고 충분하지 않은 이유

| 확인할 것 | MMV | MAMEM I/II |
|---|---|---|
| 외부에서 실제 측정한 정보인가? | 원래 tracker validity와 그 정의가 필요 | flash 생성 장치/소프트웨어/시간 기준이 필요 |
| 무엇의 신뢰도를 말하는가? | tracker 신뢰도가 EEG 신뢰도와 같다는 보장 없음 | 실제 출력 지연인지, 예정 자극/정답 annotation인지 구별 |
| 보정 중 합법적으로 알 수 있는가? | offline support의 해당 시간만; 사후 보완 제외 | support의 측정 잔차만; query의 attended frequency 제외 |
| Q·공통 정보보다 추가 정보인가? | gaze/pupil/졸음 추정으로 대체하지 않음 | nominal frequency/고정 지연 보정은 공통 기준선 |
| 학습에 실제로 작동하는가? | support 가중치가 달라져 최종 EEG decoder가 변해야 함 | 사용한 scorer가 시간 보정에 불변이면 해당 경로 중단 |

불확실한 항목은 실패로 단정하지 않되, 검증을 통과한 것으로도 세지 않는다.
자료 공개 여부, 과학적 적격성, 효과 유무는 별개 판정이다.

## 최소한의 조건부 학습 가설

MMV: 만약 **보정 중 외부 추적기의 관측 품질**이 독립적으로 기록됐고, 동일한
측정 상황이 시각 자극 관측이나 EEG support 반복성에도 영향을 준다는 근거가
있다면, Q로 학습한 support 신뢰도에 작은 M 잔차를 추가할 수 있다. 단지 tracker가
안 보였다는 사실만으로 EEG를 저품질로 간주하지 않는다. 자세 변화는 가능한
공통 원인일 뿐 입증된 기작이 아니다. 눈 감음·주의·피로 예측으로 목표를 바꾸지 않는다.
같은 class의 support를 분모가 가중치 합인 가중평균만 하면, one-shot에서 a>0에
대해 `a*x/a = x`가 되어 M의 효과가 취소된다. a=0 fallback이나 별도 regularization은
이 등식의 적용 대상이 아니다. 기작 근거가 생겨도 source prior 대비 support 불확실성의 조절처럼
one-shot에서 실제로 작동하는 연산인지 먼저 검산해야 한다. 이는 수학적 점검이며
기존 shrinkage 후보 재개나 새 효능 후보 승격의 근거가 아니다.

MAMEM: 만약 flash가 실제 출력 측정이고 예정 자극과 독립적으로 달라지는 timing
잔차가 있다면, 먼저 모든 arm에 같은 결정적 시간 보정을 준다. 그 뒤에도 남는
support 반응 불확실성을 M로 학습하는 작은 경로가 추가 후보일 수 있다. 단순
nominal-frequency annotation이나 세션 전체 고정 지연만 있다면 이 가설은 성립하지
않는다. Sin/cos 부분공간에 대한 상수 위상 회전만으로 score가 달라진다고 가정하지
않는다. [기존 위상·측정모형 검토](ssvep_phase_metadata_design_review_20260911.md).

이 가설들은 기존 gyro/source39 부정 결과를 취소하거나 재실행하는 근거가 아니다.
실제 필드가 확인되지 않은 상태에서 모델을 먼저 구현하지 않는다.

## 누출과 공정 비교

- Support 정답은 이미 비용을 지불한 학습 정보다. 따라서 support의 주파수를 안다는
  것 자체가 누출은 아니지만, 이를 새로운 외부 M의 정보 이득으로 세면 안 된다.
- Query의 `.win`, attended target의 `.flash` 간격, trial 순서/절대 경과시간으로
  정답을 복원하는 것은 금지다. Participant 분리만으로 고정 순서 누출이 사라지지 않는다.
  동시에 표시된 전체 자극 bank는 공통 정보이며 참석한 정답 하나와 구분한다.
  Exact trial index/absolute elapsed를 모든 arm에 똑같이 줘도 누출은 해결되지
  않는다. 그런 값은 별도 비용·순서 ledger에만 두고 예측 covariate에서는 제외한다.
- Q, 용량을 맞춘 Q2, Q+M, 기작에 맞는 SHAM을 동일 support/query·전처리·예산에서
  비교한다. SHAM은 자극 class·기기 같은 공통 구조까지 망가뜨리지 않도록 사전에 정의한다.
- Support-only 사용과 실제 최종 score 변화를 생성자료로 먼저 검사한다. Query 정답,
  미래 smoothing/보완값, 전체 세션 normalization은 적응·정책 선택에 사용하지 않는다.
- Source에서만 모델·정지정책을 선택한다. 사람·세션·시간 중복과 동시자극의 label
  구조가 해소되지 않으면 정확도·보정절감 실험으로 넘기지 않는다.

## 절약의 분모

버린 support도 획득 비용에 포함한다. 좋은 trial만 남았다는 이유로 보정을 적게
했다고 하지 않는다. Label 수, 획득 시간, tracker 준비/보정 시간을 각각 보고하고
같은 정확도 목표에 도달하는 실제 획득 prefix를 비교한다. MMV의 9점 tracker
calibration은 공짜가 아니며 EEG-only 기준선에 추가 준비 비용을 감춰서는 안 된다.
기존 장치가 있는 상황과 신규 장치가 필요한 상황도 구별한다.
준비/재보정 소요시간이 없으면 labeled-trial 비교와 순 보정시간 절감 주장을
분리하고, 후자는 미검증으로 남긴다.
