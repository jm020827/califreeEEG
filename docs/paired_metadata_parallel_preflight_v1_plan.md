## Signature and decision

- Representation: closed-set SSVEP EEG, paid labeled support, independent external
  acquisition measurements M, EEG-derived Q, common stimulus references.
- Bottleneck: do the named public releases actually document eligible paired M
  and offline labels, rather than target identity or postprocessed physiology?
- Allowed operation: anonymous public metadata, documentation and loader source;
  local Markdown and explicitly named saved scholarly sources. No human numeric
  arrays, annotations, CNT/EDF/MAT/ZIP/PDF bodies, fits or outcome reopening.
- Objective: retain a documented pair for a later bounded schema check, reject
  an ineligible mechanism, or park unresolved access. This is not proof of benefit.
- Feedback: documented field provenance, timing/roles, access/license and learner
  mechanism beyond Q/common correction. Unknown stays unknown.
- Failure: gaze/flash/order as class-label shortcut; long-term loss extrapolated
  to offline support; PERCLOS renamed acquisition quality; publication mistaken
  for raw availability; retries after access denial; goal drift to vigilance.

## Execution gates and anticipated differences

MMV differs from previous gyro routing by asking whether *independent original
tracker-acquisition validity* supplies support reliability information. Mere
tracker failure is not yet an EEG mechanism; posture/observation geometry may
affect both, but that is a hypothesis, not established coupling. Reject replacing
M with gaze coordinates/target identity, pupil, blink physiology or PERCLOS.
Only documented offline pairing can advance; long online commands are not labels.
Count nine-point tracker calibration and setup in any later net calibration cost.

MAMEM differs by potentially characterizing physical stimulus timing. Determine
whether .flash is hardware-measured, software-intended or derived; distinguish
simultaneous all-target drive from attended-target annotations. Query flash
periods and fixed trial order/time cannot supply the class label. Common timing
correction belongs in every fair baseline before learned-M benefit is tested.

End each lane as DOCUMENTED_PAIR_CANDIDATE (documentation only),
PARK_ACCESS_UNRESOLVED, or REJECT_M_OR_TASK_PROVENANCE. Document which gates are
unknown versus failed. Preserve old failures. No automatic learning even on a
positive documentation finding: actual bounded schema and a falsifiable learner
mechanism/controls are still needed. Root checks source consistency, file hashes,
Markdown links, JSON validity, protected protocol hashes and DB quick_check.
