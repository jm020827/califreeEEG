# 인공 수치 안정화 v1 결과

2026-09-09. **두 방법 모두 사전 고정한 수치 검증을 통과했다.** 후속 통합에는 사전 우선순위대로
`N1_SYM_CHOLESKY`를 선택한다. 이는 계산 모듈의 제한된 적격 판정이며, metadata의 추가 성능이나
보정량 감소를 확인한 결과가 아니다. 원 저보정 SSVEP 연구목표와 전체 goal은 미완료로 유지한다.

## 쉽게 설명하면

학습기가 EEG에서 필터를 계산할 때, 컴퓨터의 반올림 오차 때문에 중간 행렬이 아주 조금
비대칭이 되면서 이전 실험이 중단됐다. 이번에는 기존 실패를 지우거나 문턱만 완화하지 않고,
별도 계산 방법 두 개를 만들었다. N1은 중간 행렬을 명시적으로 대칭화하고, N2는 다른
고유값 계산 경로와 별도 미분식을 쓴다. 두 방법의 최종 답과 학습 방향을 독립적인 고정밀
계산과 비교했다. **검사한 범위에서는 답과 미분이 맞았다**는 것이 이번에 확인한 진전이다.

단일 행렬이 아니라 학습 도중 계속 변하는 행렬에서도 끝까지 작동하는지, 그리고 실제
사람에서 Q만 쓴 모델보다 metadata를 추가한 모델이 나은지는 아직 확인하지 않았다.

## 사전 고정과 실행 범위

- [설계](numerical_stability_v1_design.md), [과학 계약](../configs/analysis/numerical_stability_v1.json),
  [구현 계약](numerical_stability_v1_implementation.md)을 입력 생성 전에 고정했다.
  과학 계약 SHA `04d0968d478c795e8a0860c561fcfb881b9d510b5777c1a7ff45e65764b6fbe8`은 불변이다.
- 알려진 과거 **인공** 행렬 960개와, 구현 동결 후 처음 생성한 두 seed의 192개 조건 격자를
  모두 평가했다. 조건수 최대 10⁶, 공통 scale, 작은 top-gap, 하위 고유값 중복,
  B=C 및 다른 B를 포함한다. 새 192개는 두 기저/방향을 공유하는 격자이지 독립 표본192개가 아니다.
- 각 방법에서 1,152개 scalar 및 동일 전체 batch, 209개 사례의 S/B/C/공동 방향미분
  (방법당 836개), 잘못된 입력9개를 확인했다. 임의의 전체 Jacobian이나 모든 입력을 증명한 것은 아니다.
- 기준 계산은 저장된 binary64 값을 정확히 변환한 80자리 mpmath 해다. 생성식의 이상적
  고유벡터를 정답으로 대신 쓰지 않았다. 미분은 고정된 loss probe로 두 step의 고정밀
  중앙차분을 비교했고, 5개 사례는 120자리로 재검산했다.
- 등록 primary **1회**, 독립 audit **1회**, 재실행·추가 seed·수식/기준 수정·실패 조건 제외0이다.
  사람 EEG/M/query·optimizer·CUDA·held60·외부 요청·유료 자원은 이번 등록 연구에서 모두0이다.

## 결과

아래는 전체 scalar/batch 중 최대 오차다. 모든 조건을 통과해야 적격이라는 규칙을 적용했다.

| 검사 | 고정 상한 | N1 | N2 |
|---|---:|---:|---:|
| 원 generalized 방정식 상대 잔차 | 1e−12 | 1.46e−15 | 2.74e−15 |
| 최고 고유값 오차 | 1e−8 | 3.22e−12 | 2.51e−12 |
| C 기준 projector 오차 | 1e−6 | 1.45e−9 | 1.04e−9 |
| C 정규화 오차 | 1e−10 | 1.34e−12 | 1.79e−12 |
| 출력 비대칭 | 1e−12 | 0 | 0 |
| scalar/batch 상대 차이 | 1e−8 | 0 | 0 |
| 미분 오차 / 해당 사례 허용 오차 | 1 | 0.000173 | 0.000123 |
| 잘못된 입력 거부 | 9/9 | 9/9 | 9/9 |

미분 허용 오차는 `1e−7 + 1e−4 × max(|g|, |g_ref|)`다. 최대 절대 미분 오차는
N1 1.746e−7, N2 1.238e−7이지만, 절대항1e−7만이 아니라 사전 고정된 혼합 기준으로
판정하므로 둘 다 통과한다. 각 seed×분모 종류에서 S/B 기준 미분이 충분히 0이 아닌지도 확인했다.
두 차분 step의 최대 차이는 1.249e−33, 80/120자리 기준 비교는 최대 약5.742e−75로
각 고정 기준을 통과했다. 원 방정식 잔차를 엄밀한 최소 structured backward-error 증명으로 부르지 않는다.

과거 C2 인공 실패 위치 `row14/band0/class11`, 현재 index851의 raw-H 비대칭은 여전히
약1.0388e−12다. 새 정책의 독립 projector 오차는 N1 1.444e−12/N2 9.227e−13이었다.
즉 **같은 알려진 인공 사례에서 새 계산 정책의 답을 검증했다**. 옛 검사가 통과한 것으로
소급 변경하지 않으며, C1의 실제 사람 실패 행렬은 재접근·재실행하지 않았다.

두 방법이 모두 적격일 때 N1을 택한다는 사전 규칙을 따랐다. N2보다 실험 정확도가
우수해서 선택한 것이 아니며, N1의 Torch 기반 구현이 후속 연결에 적합하다는 구현상 선택이다.
이번에는 N1도 CPU에서만 검증했다. N2는 CPU SciPy 경로이며 CUDA-ready로 표시하지 않는다.

## 원 연구로 돌아가기 위한 다음 단계 — 제안, 미실행

1. 새 이름의 **인공 학습기 통합 검증**을 별도 범위·예산으로 고정한다. 이미 구현된
   temporal-R 경로에 N1을 연결하는 것이 현재 가장 작은 구현 경로다. 이는 아직 완성되지
   않은 C2 학습기를 추가하거나 닫힌 C1을 재개한다는 뜻이 아니다.
2. 실제 optimizer를 돌려 네 head(Q/QM/Q2/SHAM), 모든 사전 대조군, Q-only 중첩 선택,
   prefix·scaler·donor 분리, 모델 동결, 저장·복원, 독립 완료 감사를 끝까지 검사한다.
   학습 중 바뀌는 행렬의 수치 조건과 필요시 CPU/CUDA 결과도 새로 검증한다.
3. 이 경로가 통과해야 새 후보 ID·사람 입력·모델 개봉 예산을 가진 별도 유한 효능 프로그램을
   승인받아 실행할 수 있다. 동일 정보/용량 대조군을 둔 QM−Q 추가 성능, Q5/두 FULL 대비
   실제 calibration 비용과 harm을 함께 판정한다. 기존 source39는 개발자료이지 새 독립 확증이 아니다.

현재 수치 연구의 유한2방법/1회 실행 범위는 종료한다. 기존 C1/C2 실패와 이전 유효한 음성
효능 결과는 그대로다. **metadata 효과를 입증한 유망 효능 후보0, 보정량 감소 미확립**이다.
위 후속 통합/사람 실험은 이번 승인으로 자동 착수하지 않으며 held60·외부 요청·유료 자원은
계속 별도 승인 대상이다.

`academic-research`는 [공식 오차 근거와 projector 미분 근거](numerical_stability_v1_design.md#근거와-사전-결정)를
사전 가설 및 새 측정 근거와 분리하는 데 사용했다. 좁은 foundation/contrary 검색2회와
공식 HTML/소스의 관련 절을 읽었고 PDF 전체 정독이나 SSVEP 문헌 완전성을 주장하지 않는다.
`coordinate-worktree-changes`는 두 작성 경로의 격리·파일 소유권·순차 통합에 적용했다.
