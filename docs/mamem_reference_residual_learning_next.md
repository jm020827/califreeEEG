# 다음 연구: 공통 reference와 잔여 acquisition 정보 분리

2026-09-13, S001 단회 진단 결과를 본 뒤 작성한 **미실행 초안**.
원 목표는 외부 acquisition metadata를 학습에 이용하여 Q와 공통 정보 이상으로
성능·보정 부담을 개선하는지 반증 가능하게 확인하는 것이다. 목표를 reference 수정 자체로
바꾸지 않는다. 이전 M2→PSD shrinkage v2의 RETIRE도 유지한다.

## 이번 결과가 바꾸는 판단

지원 기록 bank의 14/15는 nominal의 12/15보다 좋았지만, 한 명·학습 0회다.
다른 사람들의 기록에서 배운 **공통 주파수 상수**만으로 같은 개선을 얻을 수도 있다.
또 nominal 자체는 support 없이도 이번 80% 개발 관문을 넘었다. 따라서 다음 검정의
첫 경쟁 상대는 nominal만이 아니라 강한 source-only 공통 reference여야 한다.

## 먼저 확인할 가설 — 새 실제 계약부터

기작 가설: 지원 기록의 외부 event 간격에는 공통 bank가 설명하지 못하는 재현 가능한
acquisition 차이가 있을 수 있고, 이 차이가 후속 EEG reference 선택의 불확실성을 줄일 수 있다.
그러나 A→B 실험에서 A를 B의 현재 세션 metadata로 부르면 안 된다. 다음도 이 경로를
택한다면 **cross-run 전달**로 고정하고, 결과가 나쁘다고 same-run protocol로 바꾸지 않는다.

우선 제한된 source 기록에서 공통 주파수와 잔차의 규모·재현성을 확인하는 구조 관문이
필요하다. 아직 source DIN/EEG를 새로 읽지 않았다. 다음 시작 시 정확한 파일 목록,
전역/참가자/기록별 역할, 최대 변수 읽기·분석 횟수·시간과 stop을 계약으로 먼저 고정한다.
예산 초안은 이미 개봉한 S002–S011의 필요한 공개 기록만 사용하는 1개 구조 관문이며,
이 재사용은 개발 탐색이다. 개인별 held-out 역할을 빼고 공통값을 산출해야 한다.

이 단계에서 답할 질문은 다음 세 가지다.

1. 공통 bank로 설명되는 변화가 대부분인가, 참가자/기록별 잔차가 측정의 흔들림보다 큰가?
2. 앞선 지원 기록의 잔차가 다른 기록에도 전달되는가? 이 관문에 충분한 출처·동기화 정보가 있는가?
3. 한 개의 clock-scale로 다섯 class를 설명할 수 있는가, class별 오차가 더 큰가?

마지막은 **가설**이며 이미 확인된 clock 원인이 아니다. 전체 trial 하나로 다섯 독립
주파수 보정을 식별할 수는 없다. 따라서 '총1trial 보정'을 당장 약속하지 않고,
최초 학습 비교를 설계한다면 기존 정의인 class당1/2trial(총5/10개)을 유지하는 편이 명확하다.
총1trial 전파는 source-only 구조 근거가 별도로 생길 때에만 새 후보로 제안한다.

## 구조 관문 이후의 학습 후보와 필수 대조

가능한 새 후보는 공통 reference에서 필요한 작은 보정/혼합의 신뢰도를 Q와 M로 학습하는
저용량 모델이다. 이전 모델의 PSD 혼합이 아니라 **reference 오차·전달 신뢰도**가 대상이다.
단, 구조 근거가 없으면 이 후보를 구현·학습하지 않고 종료한다.

- 먼저 **공통 bank만 쓰는 무지원 arm**을 별도로 둔다. 모든 Q/Q2/QM/SHAM에도 동일한
  source-only 공통 bank, 채널·전처리·지원 예산을 제공한다.
- Q는 같은 지원 EEG로 얻는 주파수/신호 불확실성 정보를 갖도록 설계한다. M이 단지
  약한 Q가 놓친 정보를 대체하는 것인지 강한 대조로 확인한다.
- Q2는 추가 용량 대조, SHAM은 class·지원 수 등 조건을 보존한 연결 파괴 대조다.
  source 분할에서 학습·표준화·공통 bank 산출을 모두 끝내고 held-out 참가자는 제외한다.
  Query DIN이나 query 이후 알 수 있는 기록 길이는 predictor 또는 SHAM의 조건 입력으로 쓰지 않는다.
- **학습 없이 지원 M으로 reference를 직접 정하는 대조**도 남긴다. 단순 물리적 설정
  변경으로 얻는 개선을 학습 기여로 포장하지 않는다. Nominal 무지원 대조도 보존한다.
- 같은 query에서 class당1/2trial의 정확도와 비용을 비교한다. 공통 bank의 무지원 조건이
  이미 목표 정확도를 달성하면 추가 M을 쓰는 방법의 보정 절감이라고 주장하지 않는다.
- prior M2 jitter 특징의 실패를 지우지 않는다. 새 입력 M과 출력 보정의 정의·왜 달라질지·
  예상 실패를 실행 전에 기록한다. 같은 자료에서 잘 되는 설정까지 후보를 늘리지 않는다.

이 초안은 새로운 source 평가나 gate fit을 지금 허용하는 계약이 아니다. 구조 관문 뒤
후보는 최대 1개부터 제안하고, 정확한 fit 수/검증 단위/중단 기준을 다시 고정한다.
같은 참가자의 c/d/e도 독립 참가자 확인은 아니다. 유망 후보를 얻으면 개발 결과를 보고하고
별도의 공개 독립 cohort 또는 승인된 최종 확인 계획을 제시한다. held60·외부 요청·유료는
여전히 별도 승인 대상이다.
